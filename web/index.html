Gomoku AI

A C school project — bitboard, minimax, alpha-beta — compiled to WebAssembly.

How it works

Bitboard. Each player's stones live in one 128-bit integer, one bit per cell — which is why boards stop at 11×11. Checking a win or a full board is a handful of bitwise operations.

Minimax with alpha-beta. The AI looks a few moves ahead (negamax), assumes you always answer with your best move, and prunes branches that cannot change its choice.

Crossing-lines heuristic. Every empty cell gets a score from 0 to 13 from the lines it would create — open fours, double open threes… Crossings score highest because that is how games are won. Only the best cells are searched.

In your browser. The original C code is compiled with Emscripten into three WebAssembly modules — the rules and two AI players. Each AI runs in its own Web Worker, so the page never freezes.
